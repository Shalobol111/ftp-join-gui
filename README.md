# FTP Client (Tkinter)
<img width="1000" height="660" alt="image" src="https://github.com/user-attachments/assets/609949a6-6b9a-497c-b59b-7316e88e2651" />

Графический FTP/FTPS-клиент на Python с двухпанельным файловым менеджером (локальные и удалённые файлы), логом операций и прогрессом передачи.

## Возможности

- Подключение к FTP-серверу по `Host + Port + Login + Password`.
- Поддержка обычного FTP и FTPS (через переключатель `TLS`).
- Двухпанельный интерфейс:
  - слева — локальная файловая система;
  - справа — файлы на сервере.
- Навигация по папкам двойным кликом и кнопкой `↑`.
- Передача файлов:
  - загрузка локального файла на сервер;
  - скачивание файла с сервера в текущую локальную папку.
- Прогресс-бар и отображение объёма переданных данных.
- Операции с файлами/папками:
  - создать папку;
  - удалить;
  - переименовать.
- Контекстные меню (ПКМ) для локального и удалённого списков.
- Лог-панель с событиями, ошибками и статусами.
- Потоки (`threading`) для сетевых операций без зависания GUI.

## Технологии

- Python 3.9+
- `tkinter` / `ttk` (встроенные GUI-библиотеки)
- `ftplib` (`FTP`, `FTP_TLS`)
- Стандартные модули: `os`, `threading`, `socket`, `ssl`, `shutil`, `datetime`

Внешние зависимости не требуются.

## Быстрый старт

1. Убедитесь, что установлен Python 3.9+.
2. Склонируйте репозиторий или скачайте файлы.
3. В папке проекта выполните:

```bash
python main.py
```

> На Windows также можно использовать `py main.py`.


### Важно про TLS

- Если на сервере включён обычный FTP — снимите галочку `TLS`.
- Если настроен FTPS (Explicit TLS) — оставьте `TLS` включённым.
- При ошибках подключения проверьте:
  - что сервер запущен;
  - доступность порта в брандмауэре;
  - корректность режима TLS на сервере.

## Использование

1. Подключитесь к серверу.
2. В левой панели выберите локальный файл.
3. Нажмите `Загрузить ▶` для отправки на сервер.
4. В правой панели выберите удалённый файл.
5. Нажмите `◀ Скачать` для загрузки на локальный диск.
6. Для дополнительных действий используйте кнопки под списками или ПКМ.

## Обработка ошибок

- Ошибки FTP выводятся в лог и через диалоговые окна.
- Передача файлов выполняется в фоне, чтобы интерфейс оставался отзывчивым.
- При закрытии окна соединение корректно завершается.

## Ограничения текущей версии

- Передача папок (рекурсивный upload/download) не реализована.
- Приложение рассчитано на один активный трансфер за раз.
